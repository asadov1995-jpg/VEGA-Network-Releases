# VEGA Network Launcher

Официальные установщики VEGA Launcher, подписанные манифесты, контрольные суммы и инструкции.

[VEGA Launcher 2.6.12 — предварительная версия](https://github.com/asadov1995-jpg/VEGA-Network-Releases/releases/tag/v2.6.12)

[Windows x64: VEGA.Setup.exe](https://github.com/asadov1995-jpg/VEGA-Network-Releases/releases/download/v2.6.12/VEGA.Setup.exe)

Размер установщика: 142 253 391 байт. SHA-256:

```text
49AC830F168FA591173EEB537D28021D95BC01F5451962B238A2C73E0A1D41B8
```

Перед установкой прочитайте `INSTALL_RU.txt` и `LICENSE_VEGA_RU.txt` в релизе. Закройте игру и клиент обычным способом. Профиль и установленную игру удалять не требуется.

Программа предназначена для Windows x64. Она подготавливает Minecraft 26.3, Java 25 и Fabric 0.19.5 из предусмотренных проверяемых источников. Для игры необходимы законные права на Minecraft Java Edition; VEGA ID не предоставляет лицензию Minecraft.

Для проверки скачанного файла в PowerShell:

```powershell
Get-FileHash -LiteralPath '.\VEGA.Setup.exe' -Algorithm SHA256
```

Сравните результат с указанным выше значением и `SHA256SUMS.txt`. Подпись ECDSA манифеста проверяется внутри системы установки/обновлений. Она не является подписью издателя Windows: Authenticode-подписи у EXE пока нет. Не отключайте защиту Windows для установки.

В этой предварительной версии само приложение обновляют проверенным новым установщиком. Проверка игровых файлов в клиенте скачивает необходимые компоненты и повторно использует исправные файлы. Автоматическая публичная доставка обновлений самого приложения пока не включена.

При ошибке сохраните версию, этап действия и безопасный код из журнала. Не публикуйте пароли, recovery-коды, токены, базу аккаунтов, полный профиль Windows или игровые сохранения. Не принуждайте понижение версии изменением квитанции или DPAPI-состояния.

Условия использования VEGA Launcher приведены в `LICENSE_VEGA_RU.txt` соответствующего релиза; сторонние компоненты распространяются на своих условиях.
